# Go AI Verification Harness Syllabus

## Phase 1 – 1 Week
- Introduction to Go tooling
- Setting up Go module
- Writing `goai-verifier` CLI
- Table‑driven test harness

## Phase 2 – 2 Weeks
- Integrating `gofmt`, `go vet`, `go test`
- Adding `gosec` scan
- Implement simple hallucination detector
- Draft CI workflow (GitHub Actions)

## Phase 3 – 1 Week
- Unit tests for harness
- Integration tests against example repo
- Documentation (README, CONTRIBUTING)

## Phase 4 – 1 Week
- Release candidate build
- Publish binary in GitHub release
- Write automated PR reviewer using `github-code-review`

## Deliverables
- `goai-verifier` binary
- YAML config template
- JSON schema for report
- CI workflow file
- README with usage examples

End Syllabus.
