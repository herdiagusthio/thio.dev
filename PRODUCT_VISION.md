# Product Vision & Roadmap: thio.dev

## Vision: The System Console
Evolve thio.dev into a high-density 'System Console' aesthetic. A live changelog of engineering decisions (second-brain) built as a public-facing performance telemetry interface.

## Roadmap: The Triple-Threat
Align site structure to three core 'Threat' vectors:

1. **The Work (Engineering Lab):**
   - High-fidelity logs of system design and architectural decisions.
   - Built on `second-brain` SSG.

2. **The Lab (Telemetry & Patterns):**
   - Public-facing patterns/blueprints visualized as static telemetry.
   - Accessible from the right-hand column (Architecture Blueprint).

3. **The Thoughts (Learning Diary):**
   - Journal entries linking work to philosophy, ethics, and technical reasoning.

## Next Steps
- Implement 3-column structural grid (Telemetry/Feed/Context).
- Standardize grayscale tokens (strict UI).
- Automate deployment via GitHub Actions as currently spec'd.
